## Some things I've built

### Reddit Pulse

A data project for exploring trends in Pakistani Reddit communities.

I built a pipeline around publicly available Reddit data, processed large local datasets with Parquet, used Python and PyTorch for enrichment, stored the processed data in Supabase, and built a Next.js dashboard to explore the results.

The project started after Reddit API access was unavailable to me, so I worked around that by building the data pipeline around publicly available dumps.

### Student Risk Prediction

My Final Year Project focused on predicting whether a university student was at risk of failing before their final exams.

I collected my own dataset, cleaned and prepared the data, trained machine learning models, and built a dashboard around the final model. The system could use a student's performance during the semester to estimate their risk and provide useful information through separate student and teacher views.

### Path of Exile Tools

I've built several tools around Path of Exile because it is a convenient excuse to build software around something I already spend time with.

Some of these include a clip review application using the Twitch and YouTube APIs, a trade bookmark browser extension, and an economy and trends tracker.

The clip review application was built with Next.js, TypeScript, Tailwind, Prisma and Supabase and was designed to replace a manual process of finding, downloading and reviewing clips.

### Homelab

I also run a Linux based homelab where I experiment with Docker, networking, self-hosted services, storage, media servers, automation and GPU workloads.

It has been a good way to learn things that are difficult to understand properly by only reading about them, especially networking, Linux administration, containers and infrastructure.
